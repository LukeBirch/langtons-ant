# Langton's Ant

A C implementation of **Langton's Ant**, a cellular automaton demonstrating how simple rules can produce complex behaviour.

## Features

* Langton's Ant simulation
* Black and white grid cells
* Ant movement and direction handling
* Terminal visualisation using `ncurses`
* Modular C source and header files

## Rules

* **White cell:** Turn right, change to black, move forward.
* **Black cell:** Turn left, change to white, move forward.

## Technologies

* C
* ncurses
* Make
* Linux/Unix
